# 📊 Pesquisa de Opinião - TudoWeb

## 📌 Sobre o projeto

Este projeto foi desenvolvido em Python para realizar uma pesquisa de opinião com clientes da empresa fictícia **TudoWeb**.

O programa coleta informações de **nome, idade e opinião sobre o atendimento** e, ao final, apresenta a quantidade de respostas **EXCELENTE** e **RUIM**.

## 🎯 Objetivo

Praticar o uso de:

- Estrutura de repetição `while`
- Estruturas de decisão `if` e `elif`
- Entrada de dados com `input()`
- Variáveis e contadores
- Exibição de resultados

## 📝 Funcionamento

O programa realiza a pesquisa com **50 entrevistados**.

Para cada entrevistado, são solicitados:

- Nome
- Idade
- Opinião sobre o atendimento

As opções de opinião são:

| Opção | Avaliação |
|---|---|
| 1 | EXCELENTE |
| 2 | BOM |
| 3 | RUIM |

Ao finalizar a pesquisa, o programa exibe:

- Quantidade de respostas **EXCELENTE**
- Quantidade de respostas **RUIM**

## 💻 Tecnologias utilizadas

- Python 🐍
- Visual Studio Code
- GitHub

## ▶️ Como executar

1. Instale o Python.
2. Abra o projeto no Visual Studio Code.
3. Abra o arquivo `pesquisa.py`.
4. Execute o programa pelo terminal.
5. Informe os dados solicitados para cada entrevistado.

## 🧪 Teste

Foi realizado um teste com **10 entrevistados** para verificar o funcionamento do programa.

Após a validação, o programa foi configurado novamente para realizar a pesquisa com **50 entrevistados**, conforme solicitado na atividade.
